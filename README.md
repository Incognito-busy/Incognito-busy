## 🚀 Featured Projects

### 1. Microplastic Detection System
A database-driven system designed to manage microplastic detection data and spectral analysis.

**Technologies:** React.js, Node.js, Express.js, MySQL, Python

### 2. Renewable Energy Prediction
A machine learning project that predicts renewable energy production using environmental and weather-related features.

**Technologies:** Python, Pandas, Scikit-learn, Linear Regression, Random Forest

### 3. Fashion Style Clustering
An unsupervised machine learning project that identifies fashion-style groups using product features and clustering techniques.

**Technologies:** Python, PCA, K-Means, Gaussian Mixture Models

### 4. Indoor Navigation Path Prediction
A probabilistic path prediction project that uses sequential observations to identify the most likely indoor movement path.

**Technologies:** Python, Hidden Markov Model, Viterbi Algorithm

### 5. PRISM – Agentic Code Intelligence
A collaborative project exploring code intelligence using embedding models, language models and score fusion.

**Technologies:** EmbeddingGemma, Qwen, Semantic Embeddings
